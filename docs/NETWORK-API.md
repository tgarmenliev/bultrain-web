# Спецификация: снимка на мрежата за сайта ("Живата мрежа")

Цел: сайтът показва реалното състояние на жп мрежата, честно и без да товари сървъра.
Един JSON файл, който сървърът **изчислява сам на всеки 5 минути** и обслужва от кеша.
Посетителите никога не задействат изчисление.

`GET /v1/network` (име по твой избор)

Заглавия: `Cache-Control: public, max-age=300`, `Access-Control-Allow-Origin: <сайта>` (и localhost за разработка), gzip.

```json
{
  "generatedAt": "2026-10-04T18:05:00Z",
  "realtime": { "available": true, "feedUpdatedAt": "2026-10-04T18:04:41Z" },
  "summary": {
    "running": 143,
    "withRealtime": 121,
    "onTimePercent": 71,
    "avgDelayMin": 4,
    "maxDelay": { "min": 38, "type": "БВ", "trainNum": "8627", "to": "Бургас" }
  },
  "boards": {
    "sofia":   { "name": "София",   "trains": [ /* до 8, същият обект като сегашния endpoint */ ] },
    "plovdiv": { "name": "Пловдив", "trains": [] },
    "varna":   { "name": "Варна",   "trains": [] },
    "burgas":  { "name": "Бургас",  "trains": [] }
  }
}
```

## Значения
- `running`: влакове в движение в момента (между първо тръгване и последно пристигане по разписание).
- `withRealtime`: от тях, за колко има данни от GTFS-Realtime.
- `onTimePercent`, `avgDelayMin`: само по влаковете с реални данни. "Навреме" = закъснение под 5 мин (или както го смята приложението).
- `boards.*.trains[]`: същата структура като сегашния ти endpoint (`direction, time, isDelayed, delayedTime, delayInfo, type, trainNum`).

## Правило за честност
Ако потокът за реално време не е наличен: `realtime.available = false`, а `onTimePercent`, `avgDelayMin`, `maxDelay` са `null`.
Никога не се оценява и не се попълва число. Сайтът тогава показва "няма данни на живо".

## Какво прави сайтът
- Взима файла при зареждане и после на 5 мин, само докато табът е видим.
- "Обновено преди X мин" се смята от `generatedAt`, не от часовника на посетителя.
- Ако файлът е по-стар от 15 мин, сайтът казва това открито.

## По-късно (радар, не сега)
`trains: [{ type, trainNum, from, to, delayMin, progress, lat, lon }]` за всички влакове в движение (около 150, около 20 KB).
